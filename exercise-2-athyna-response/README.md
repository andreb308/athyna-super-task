# Athyna Public Job Board Client (Exercise 2)

This directory contains the Next.js 15 application implementing **The High-Intent Candidate Loop** for Athyna's public job board.

> [!TIP]
> For the complete submission overview, architectural decision records, feature video link, and trade-off analysis, please refer to the primary repository [**`README.md`**](../README.md).

---

## Quick Start

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Run the Vitest test suite (22 files, 126 tests)
npm test

# Build for production
npm run build
```

The app will be available at [http://localhost:3000](http://localhost:3000). It connects directly to Athyna's live development API (`https://develop.api.athyna.com`) with zero configuration required.
